# Public corpus: provenance records

These files are **provenance records** in the simplified source-docs convention this repo
uses: for each public source, one record stating where it lives, when it was verified, and
what it claims. The **raw artifacts are deliberately not captured** here (they are other
people's published pages); the records are cite-only. Every claim was verified by fetching
and reading the source on 2026-08-26.

The convention, in one breath: sources are authoritative, the wiki (`docs/wiki/`) is a
derived representation that cites them and can be rebuilt from them at any time. Wiki pages
cite these records; the records cite the outside world.
