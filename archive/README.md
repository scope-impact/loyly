# Archive

This directory preserves retired implementations that still carry design or migration
evidence. Archived code is not an active runtime dependency and its commands are not part
of the supported development workflow.

- [`legacy-harness/`](legacy-harness/) is the former shell/Babashka Löyly harness. ORC and
  the Pi extension replaced it; it remains a behavioral-parity reference for refusal,
  skip, timeout, scoring, and evidence behavior.
