# impl/

Intentionally empty: the Löyly app's implementation is a build product, regenerated by the
harness from `docs/plan/` and not maintained here. Since 2026-11-08 the new harness runs the
regeneration cycles, with the legacy harness (`archive/legacy-harness/`) as the reference
(`.pi/spec/decisions.md`, "The switch to the new harness"). To build it yourself, the way in is
`docs/wow/harness.md` §4 (the read order) and `docs/plan/01-booking-core/` (the slice to build).

Whatever you build, the gate's contract is two executables here:

- `test.sh`: runs the whole suite, exits non-zero on any failure
- `start.sh PORT`: serves the app over HTTP on PORT

Then the legacy gate, `verify.sh`, ratifies the claim. In this repo `harness/` measures the Pi
harness, so run it with the archived tools in `harness/`, as the shadow runs did.
